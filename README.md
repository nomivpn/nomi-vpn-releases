# Nomi VPN for Windows

Official Windows downloads for Nomi VPN. The desktop app lets you connect to the VPN, choose a location, manage routing rules, and get help through the built-in support chat.

## Download and install

1. Open the [latest release](https://github.com/nomivpn/nomi-vpn-releases/releases/latest).
2. Under **Assets**, download the Windows x64 installer. Its name ends in `Windows-x64-Setup.exe`.
3. Run the installer. You can choose the interface language and whether to create a desktop shortcut.

The installer is for 64-bit Windows. The application supports English and Russian. To switch languages after installation, open **Settings → General → Interface language**.

## Verify a download

Each release lists the installer's SHA-256 checksum. In PowerShell, run `Get-FileHash -Algorithm SHA256 .\NomiVPN-1.0-Windows-x64-Setup.exe` from the download folder, then compare the result with the checksum in the release notes.
